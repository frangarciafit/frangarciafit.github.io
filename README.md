# Francisco García Fitzsimons

Personal site for backend work. English page, one screen of projects.

## Projects on the page

- **DYS Total Assistance.** Backend of the public quoting and issuance site, and of the internal sales panel. The repository stays private. The public product is [dysassistance.com](https://dysassistance.com).
- **Investment and cash tracker.** Collaboration. Reimbursements and net totals. Repos: [fci-backend](https://github.com/joacodimaro97/fci-backend), [simulacion-inversion](https://github.com/joacodimaro97/simulacion-inversion).
- **CAICH.** Client API for a sports club. Express, MySQL, Sequelize. [caich-back](https://github.com/Dys-tech-developers/caich-back).

## Run locally

Open `index.html` in a browser, or:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Resumen

Portfolio de una página, en inglés. El panel de DYS se cuenta como experiencia y se enlaza el sitio público de cotización. El registro de gastos y CAICH se enlazan como proyectos compartidos.
